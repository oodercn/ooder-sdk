## 2. 核心设计原则

### 2.1 分层解耦

| 层级 | 职责 | 状态管理 | 编排能力 |
|------|------|----------|----------|
| Agent SDK | 协议层，原子操作 | 无状态 | 无编排 |
| SceneEngine | 场景层，业务逻辑 | 有状态 | 场景级编排 |
| Skill Runtime | 执行层，资源管理 | 运行时状态 | 无编排 |

### 2.2 职责分离

```
CLI (交互) ──▶ Agent SDK (协议) ──▶ SceneEngine (编排) ──▶ Skill (执行)
  │               │                    │                    │
  │               │                    │                    │
  ▼               ▼                    ▼                    ▼
用户输入      命令转换          场景上下文          原子操作
格式化        协议封装          生命周期管理         资源操作
```

### 2.3 扩展机制

- **水平扩展**：通过 SPI 机制扩展服务
- **垂直扩展**：通过 SceneEngine 编排复杂流程
- **插件扩展**：通过 Skill 机制扩展功能

## 3. 关键概念映射

| 概念 | Agent SDK 层 | SceneEngine 层 | Skill 层 |
|------|-------------|---------------|---------|
| 操作单元 | Command | Capability | Service Method |
| 执行方式 | 原子操作 | 编排执行 | 具体实现 |
| 状态管理 | 无状态 | 场景状态 | 运行时状态 |
| 通信方式 | 消息队列 | 事件总线 | 服务调用 |
