CAP 能力路由体系

CAP (Capability Address Protocol) 是 SceneEngine 的核心能力寻址方案，提供统一的能力地址空间管理。

微/小/大三层架构

SceneEngine 2.3 采用微/小/大三层架构，支持从开发测试到企业级生产的平滑演进，实现降级兼容和弹性部署。

数据流架构

用户请求从对话服务进入，通过RAG Pipeline进行知识检索增强，同时通过Tool Registry进行工具匹配和调用，最终由LLM Service生成响应。

RAG 检索增强生成流程

RAG (Retrieval-Augmented Generation) 是检索增强生成的核心技术，通过将用户查询向量化，从知识库中检索相关片段，增强提示后由大模型生成精准回答。

Function Calling 工具调用流程

Function Calling 允许 LLM 识别需要调用的外部工具，生成结构化的工具调用请求，执行后返回结果，实现 Agent 与外部系统的交互。

模块依赖关系

SceneEngine 采用分层依赖设计，上层模块依赖下层模块，确保架构清晰、解耦合理。
