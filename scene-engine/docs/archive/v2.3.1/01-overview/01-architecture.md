## 核心组件

| 组件 | 职责 | 关键类 |
|------|------|--------|
| **对话服务** | 多轮对话管理、上下文维护 | `ConversationService` |
| **知识库服务** | 文档管理、知识检索 | `KnowledgeBaseService` |
| **术语服务** | 术语解析、缩写扩展 | `TerminologyService` |
| **交互反馈** | 数据收集、自动学习 | `InteractionFeedbackService` |
| **RAG Pipeline** | 检索增强生成 | `RagPipeline` |
| **工具编排** | 工具注册、调用执行 | `ToolOrchestrator` |

## 数据流

```
用户输入 → 术语解析 → 知识检索 → RAG增强 → LLM生成 → 结果反馈
    ↓           ↓           ↓          ↓          ↓          ↓
   原始       规范化      向量检索    提示增强    智能回复   知识库更新
   查询       查询
```

## 命名规范

| 层级 | 规则 | 示例 |
|------|------|------|
| SDK类 | 简洁命名 | `DriverChatRequest` |
| SE类 | `Scene`前缀 | `SceneChatRequest` |
| 配置类 | `Properties`后缀 | `ConversationProperties` |
