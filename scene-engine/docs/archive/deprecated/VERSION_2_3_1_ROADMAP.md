# 版本 2.3.1 实施路线图

**版本**: 2.3.1

**状态**: 规划中  

---

## 一、版本范围定义

### 1.1 版本目标

版本 2.3.1 聚焦于 **LLM 上下文核心能力** 的建设，为后续智能场景技能奠定基础设施。

### 1.2 包含功能

| 功能模块 | 说明 | 优先级 |
|---------|------|--------|
| **场景上下文管理** | LlmSceneContext 生命周期管理 | P0 |
| **NLP 上下文管理** | 组件化 NLP 上下文支持 | P0 |
| **上下文传递** | A2A 协议上下文传递能力 | P0 |
| **RAG 基础能力** | 知识检索增强基础框架 | P1 |
| **LLM 多模型支持** | LLM Pool 和路由策略 | P1 |

### 1.3 不包含功能（延后到 2.4.0）

- 智能安装引导（完整版）
- 复杂场景编排
- 高级 RAG 功能（重排序、引用追踪）
- 多模态支持
