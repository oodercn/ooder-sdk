微/小/大部署架构

微层 (Micro Layer) - 开发测试环境

  • 零配置、快速启动
  • 内存存储，重启丢失
  • 适合：开发测试、离线演示
  • 成本：零额外投入

小层 (Small Layer) - 小团队/边缘部署

  • 轻量级、本地持久化
  • SQLite向量存储，单机部署
  • 适合：小团队、边缘设备、私有化部署
  • 成本：低硬件投入

大层 (Large Layer) - 企业级生产环境

  • 高可用、分布式
  • Milvus向量库、集群部署
  • 适合：大规模生产、企业级应用
  • 成本：按需扩展

RAG检索增强生成

让AI具备企业专属知识

用户提问 → 向量化查询(LLM.embed) → 知识检索(VectorStore.search) → 提示增强(检索结果+用户问题) → 智能回答(LLM.chat)

核心价值

  • ✅ 基于企业知识库回答，准确可靠
  • ✅ 支持文档、网页、文本等多种知识来源
  • ✅ 自动分块、向量化、索引
  • ✅ 答案可追溯，标注来源

Function Calling工具调用

让AI具备业务执行能力

用户需求 → LLM理解(识别需要调用的工具) → 工具选择(从工具注册表匹配) → 执行工具(知识检索/数据库查询/API调用) → 结果整合(LLM生成最终回答)

核心价值

  • ✅ AI可执行复杂业务流程
  • ✅ 支持多工具协同编排
  • ✅ 业务逻辑模块化封装
  • ✅ 易于扩展新能力

三层知识架构

支持多粒度知识管理

场景知识层 (Scene Layer) - 优先级最高

特定场景的专属知识，例如：产品A知识库、项目B文档库

专业知识层 (Professional Layer) - 优先级中等

行业/领域通用知识，例如：技术文档、行业标准、法规政策

通用知识层 (General Layer) - 优先级基础

企业通用知识，例如：公司制度、流程规范、常见问题

典型用户故事：智能文档助手

场景：企业员工查询公司制度

传统方式：

  • 翻阅大量文档
  • 咨询HR部门
  • 耗时耗力

Ooder方案：

员工: "请假流程是什么？需要提前几天申请？" AI助手: "根据《员工手册》第3.2条规定： 1. 年假需提前5个工作日申请 2. 病假需提供医院证明 3. 流程：提交申请 → 部门审批 → HR备案 参考文档：《员工手册》第3.2条"

价值：查询时间从30分钟缩短至30秒

典型用户故事：新人培训助手

场景：新员工入职培训

传统方式：

  • 集中培训
  • 发放大量文档
  • 培训效果难评估

Ooder方案：

新员工: "公司的绩效考核周期是多久？" AI助手: "公司绩效考核分为： 1. 月度考核：每月25日 2. 季度考核：每季度末 3. 年度考核：每年12月 详细指标请参考《绩效考核制度》"

价值：培训周期缩短40%，培训成本降低60%
