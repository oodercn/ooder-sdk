# Scene Engine v3.0.0 安装指南

## 概述

Scene Engine v3.0.0 提供三种规模的安装方案，适应不同场景需求。

| 规模 | 适用场景 | 存储实现 | LLM 实现 | 向量实现 |
|------|----------|----------|----------|----------|
| **微型 (Tiny)** | 开发测试、单机部署 | 文件存储 | Ollama 本地 | 内存向量 |
| **小型 (Small)** | 小团队、单服务 | MySQL/PostgreSQL | 远程 API | Milvus Lite |
| **企业级 (Enterprise)** | 大型企业、高可用 | 分布式存储 | 多模型路由 | 分布式向量库 |

---

## 一、微型安装 (Tiny)

### 1.1 适用场景

- 开发测试环境
- 个人学习研究
- 快速原型验证
- 单机低负载场景

### 1.2 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 10 GB | 20 GB |
| Java | JDK 17+ | JDK 21 |
| Ollama | 可选 | 推荐 |

### 1.3 安装步骤

## 二、小型安装 (Small)

### 2.1 适用场景

- 小型团队 (5-20人)
- 生产环境试用
- 中等负载场景
- 需要数据持久化

### 2.2 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 4 核 | 8 核 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 50 GB | 100 GB SSD |
| Java | JDK 17+ | JDK 21 |
| 数据库 | MySQL 8.0 / PostgreSQL 14 | MySQL 8.0 |
| 缓存 | Redis 6.0 (可选) | Redis 7.0 |
| 向量库 | Milvus Lite | Milvus 2.3 |

## 三、企业级安装 (Enterprise)

### 3.1 适用场景

- 大型企业 (100+ 用户)
- 高可用生产环境
- 高负载场景
- 多租户场景

## 五、配置参考

### 5.1 完整配置项

```yaml
scene:
  engine:
    # 驱动类型: tiny | small | enterprise
    driver: tiny
    
    # 降级实现开关
    fallback:
      enabled: true
    
    # RAD 集成开关
    rad:
      enabled: false
    
    # Tiny 驱动配置
    tiny:
      storage:
        path: ./data
      llm:
        endpoint: http://localhost:11434
        model: llama2
    
    # Small 驱动配置
    small:
      storage:
        table-prefix: scene_
      llm:
        endpoint: https://api.openai.com/v1
        api-key: ${OPENAI_API_KEY}
        model: gpt-3.5-turbo
    
    # Enterprise 驱动配置
    enterprise:
      llm:
        endpoints: |
          openai:https://api.openai.com/v1:gpt-4
          azure:https://xxx.openai.azure.com:gpt-35-turbo
        routing:
          default: openai
          fallback: azure
```

### 5.2 环境变量

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `OPENAI_API_KEY` | OpenAI API Key | `sk-xxx` |
| `AZURE_OPENAI_KEY` | Azure OpenAI Key | `xxx` |
| `DB_PASSWORD` | 数据库密码 | `your_password` |
| `REDIS_PASSWORD` | Redis 密码 | `your_password` |

## 六、故障排除

### 6.1 常见问题

| 问题 | 解决方案 |
|------|----------|
| 启动失败: 找不到驱动 | 检查 `scene.engine.driver` 配置 |
| 数据库连接失败 | 检查数据库地址、用户名、密码 |
| LLM 调用失败 | 检查 API Key 和端点配置 |
| 向量检索无结果 | 检查向量库连接，Tiny 模式重启后丢失 |

### 6.2 日志查看

```bash
# 查看启动日志
tail -f logs/scene-engine.log

# 查看驱动加载日志
grep "Driver" logs/scene-engine.log

# 查看 LLM 调用日志
grep "LLM" logs/scene-engine.log
```
