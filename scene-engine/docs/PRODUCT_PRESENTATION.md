# 第一部分：产品概述

## 1.1 产品定位

**Ooder SceneEngine - 企业级AI能力引擎**

- **定位**: 为企业提供统一的AI能力编排与场景驱动平台
- **愿景**: 让AI能力像搭积木一样简单组合，快速构建业务应用
- **使命**: 降低企业AI应用门槛，加速数字化转型

# 第三部分：核心能力

## 3.1 RAG检索增强生成

**让AI具备企业专属知识**

```
用户提问
    │
    ▼
┌─────────────┐
│  向量化查询  │ ──── LLM.embed()
└─────────────┘
    │
    ▼
┌─────────────┐
│  知识检索    │ ──── VectorStore.search()
└─────────────┘
    │
    ▼
┌─────────────┐
│  提示增强    │ ──── 检索结果 + 用户问题
└─────────────┘
    │
    ▼
┌─────────────┐
│  智能回答    │ ──── LLM.chat()
└─────────────┘
```

**核心价值**:
- ✅ 基于企业知识库回答，准确可靠
- ✅ 支持文档、网页、文本等多种知识来源
- ✅ 自动分块、向量化、索引
- ✅ 答案可追溯，标注来源

## 3.2 Function Calling工具调用

**让AI具备业务执行能力**

```
用户需求
    │
    ▼
┌─────────────┐
│  LLM理解    │ ──── 识别需要调用的工具
└─────────────┘
    │
    ▼
┌─────────────┐
│  工具选择    │ ──── 从工具注册表匹配
└─────────────┘
    │
    ├─────── 知识检索工具 ──────┐
    ├─────── 数据库查询工具 ────┤
    └─────── API调用工具 ───────┘
    │
    ▼
┌─────────────┐
│  结果整合    │ ──── LLM生成最终回答
└─────────────┘
```

**核心价值**:
- ✅ AI可执行复杂业务流程
- ✅ 支持多工具协同编排
- ✅ 业务逻辑模块化封装
- ✅ 易于扩展新能力

# 第四部分：应用场景

## 4.1 企业办公场景

| 场景 | 解决方案 | 业务价值 |
|------|----------|----------|
| **智能文档助手** | RAG + 知识库 | 员工快速查询制度流程，效率提升50% |
| **会议纪要整理** | 多轮对话 + 知识贡献 | 自动整理会议内容，知识沉淀 |
| **跨部门协作** | 权限管理 + 知识分享 | 打破信息孤岛，促进协作 |
| **新人培训** | 个人知识库 + 智能问答 | 缩短适应期，降低培训成本 |
| **项目知识管理** | 批量导入 + 场景分类 | 项目经验传承，避免重复造轮子 |

## 4.2 典型用户故事

### 故事1：智能文档助手

**场景**: 企业员工查询公司制度

**传统方式**:
- 翻阅大量文档
- 咨询HR部门
- 耗时耗力

**Ooder方案**:
```
员工: "请假流程是什么？需要提前几天申请？"
AI助手: "根据《员工手册》第3.2条规定：
        1. 年假需提前5个工作日申请
        2. 病假需提供医院证明
        3. 流程：提交申请 → 部门审批 → HR备案
        参考文档：《员工手册》第3.2条"
```

**价值**: 查询时间从30分钟缩短至30秒

### 故事2：新人培训助手

**场景**: 新员工入职培训

**传统方式**:
- 集中培训
- 发放大量文档
- 培训效果难评估

**Ooder方案**:
```
新员工: "公司的绩效考核周期是多久？"
AI助手: "公司绩效考核分为：
        1. 月度考核：每月25日
        2. 季度考核：每季度末
        3. 年度考核：每年12月
        详细指标请参考《绩效考核制度》"
```

**价值**: 培训周期缩短40%，培训成本降低60%
